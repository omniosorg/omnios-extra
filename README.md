# OmniOS Extra Package Repository

This repository holds the build recipes for the packages delivered in the
OmniOS **extra** IPS repository - additional software that is useful to a
broad range of OmniOS users but that does not belong in the core operating
system.

Packages are built and delivered for all currently supported OmniOS
releases, and are available from the `extra.omnios` publisher at
`https://pkg.omnios.org/<release>/extra/`.
